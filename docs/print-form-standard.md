# TEF Stock — Print Form Standard

มาตรฐานนี้ใช้ตรวจแบบฟอร์มที่สร้างจากระบบทุกประเภท:

- ใบเบิกพัสดุ / Borrowing Form
- ใบจ่ายพัสดุ / Issue Form
- ใบคืนพัสดุ / Return Form
- ใบย้ายพัสดุ / Transfer Form
- แบบฟอร์มกระทบยอดตรวจนับ / Stock Count & Reconciliation

## หัวกระดาษที่ต้องเหมือนกัน

1. ชื่อสมาคมภาษาไทยอยู่ด้านบน
2. ชื่อภาษาอังกฤษอยู่บรรทัดถัดไป
3. ตราสมาคมอยู่มุมขวาบน
4. เส้นคั่นหัวกระดาษอยู่ใต้หัวหนังสือ
5. ชื่อแบบฟอร์มอยู่กึ่งกลาง และมีชื่อภาษาอังกฤษกำกับ
6. เลขที่เอกสารและวันที่อยู่ตำแหน่งเดียวกันในทุกแบบฟอร์ม

## เนื้อหาและตาราง

- ป้ายข้อมูลสำคัญต้องมีไทย / English คู่กัน
- ตารางใช้เส้น ขนาดตัวอักษร และระยะห่างชุดเดียวกัน
- รหัส รายการ จำนวน และหมายเหตุต้องอ่านได้เมื่อพิมพ์ A4
- รูปแบบวันที่ต้องแสดงไทยและ ค.ศ. ตามมาตรฐานเดียวกัน
- หน้าต่อเนื่องต้องมีหัวตารางหรือส่วนต่อเนื่องที่อ่านรู้เรื่อง
- ลายเซ็น ผู้ขอ ผู้จ่าย/ผู้รับผิดชอบ และผู้อนุมัติใช้แนวเดียวกัน

## ตรวจพรีวิวก่อน Merge

- [ ] Borrow มีหัวกระดาษและโลโก้มุมขวาบน
- [ ] Issue มีหัวกระดาษและโลโก้มุมขวาบน
- [ ] Return มีหัวกระดาษและโลโก้มุมขวาบน
- [ ] Transfer มีหัวกระดาษและโลโก้มุมขวาบน
- [ ] Count มีหัวกระดาษและโลโก้มุมขวาบน
- [ ] ไทยและ English ไม่ทำให้หัวกระดาษล้น
- [ ] พิมพ์ A4 แล้วไม่ตัดตาราง/ลายเซ็น
- [ ] URL ท้ายเอกสารและเลขหน้าแสดงถูกต้อง

## หลักความปลอดภัย

การตรวจพรีวิวต้องใช้ข้อมูลจำลองหรือเอกสารทดสอบบน staging เท่านั้น ห้ามสั่งบันทึกหรือแก้ไขสต็อก Production เพื่อทดสอบแบบฟอร์ม
